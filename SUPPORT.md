# Support

## Usage questions

Start with the [README](README.md) and the [command reference](docs/reference.md). The command reference covers flags, output formats, exit codes, redaction, and troubleshooting.

## Bug reports

Open a GitHub issue with the bug report form. Include your Node.js version, the command you ran, the error message, and a small synthetic or redacted example when it helps explain the problem.

Do not post Codex rollout files, raw transcripts, source code from private projects, credentials, or unredacted handoff documents. ExtraLife reads private session data, so even a failed transcript may contain sensitive content.

## Feature requests

Use the feature request form and describe the user problem and the result you want. Search existing requests first so related ideas can be discussed together.
