# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/rroy233/extralife/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

Repository maintainers: enable **Private vulnerability reporting** in the repository's **Settings → Code security and analysis** after creating the GitHub repository.

Please include the affected version, impact, and a minimal reproduction. Do not include real Codex transcripts, credentials, or private project data in a report unless essential; redact them first.

## Supported versions

Security fixes are made for the latest published version. Users should upgrade to the latest release.
