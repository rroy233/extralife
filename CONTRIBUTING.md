# Contributing

Bug reports, feature requests, and focused pull requests are welcome.

- Search existing issues before opening a new one.
- Use the issue forms to report a bug or suggest a feature.
- Describe the user problem and the expected behavior in a pull request.
- Do not share raw Codex sessions, private source code, credentials, or unredacted handoff documents.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

For usage help, see [SUPPORT.md](SUPPORT.md). Report security issues using the private process in [SECURITY.md](SECURITY.md).
